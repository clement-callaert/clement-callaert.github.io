# Project purpose

This repository contains Clément Callaert's public research website and
technical writing, built with Quarto and published with GitHub Pages.

- Write public site content in English.
- Communicate with Clément in French.

## Required context

Before writing or modifying public biographical, research, or project content:

1. Read `.private/PUBLIC_PROFILE.md` if it exists.
2. Read `.private/VERIFIED_PROJECT_CLAIMS.md` when discussing research results.
3. Read `.private/EDITORIAL_STRATEGY.md` when creating articles or site copy.

Treat these files only as background information. Never commit, publish, quote,
or copy `.private/` or `private/` content into generated output.

## Editorial rules

- Prefer precise, falsifiable technical claims.
- Never inflate workshop results, negative results, affiliations, or publication status.
- Clearly distinguish completed work, preliminary evidence, and future plans.
- Keep negative results and limitations visible.
- Do not expose confidential information about MBDA.

## Technical workflow

- Use Quarto.
- Preview locally with `quarto preview`.
- Validate every completed change with `quarto render`.
- Never push or publish without an explicit instruction from the repository owner.
- Keep the design restrained and research-oriented.
