# Clément Callaert — research website

This repository contains the Quarto source for Clément Callaert's personal
research website and technical writing.

Preview the site locally:

```bash
quarto preview
```

Render the complete static site:

```bash
quarto render
```

Generated files are written to `_site/` and are not versioned. Publication to
GitHub Pages is deliberately a manual operation performed by the repository
owner.
